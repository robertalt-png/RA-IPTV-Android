# NenoTV Admin v0.1

A deliberately simple Android companion for the NenoTV owner.

- Read-only by design.
- Pair with the 10-character code generated by NenoTV Operations & Support.
- Period selector: Today / This week / This month.
- Overview: revenue, orders, visitors, Pro customers, trials and service status.
- Customer summary, order summary and hidden advanced details.
- Access token is encrypted with Android Keystore AES-GCM.
- No credentials or API token are embedded in the APK or repository.

The backend already exists on nenotv.com under the `nenotv-dashboard/v1` REST namespace.
